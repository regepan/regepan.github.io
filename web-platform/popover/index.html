HTMLだけで「開く・閉じる」ができる Popover API

メニューや補足パネルを表示するために書いていた、開閉処理、外側クリック、Escキー、重なり順の管理。その多くをブラウザに任せられます。

Baseline 2025対応状況：2026年9月1日確認

Popover APIは、ページのほかの内容より手前に一時的なUIを表示するための仕組みです。要素にpopover属性を付け、ボタンのpopovertargetから対象のIDを指定するだけで、JavaScriptなしでも開閉できます。

この記事で使うpopover="auto"、ライトディスミス、開閉イベントの対応範囲です。iOS / iPadOS 17〜18.2は外側タップで閉じない既知の制限があります。

まずは触ってみる

「操作メニューを開く」を押してください。メニューの外側をクリックするか、Escキーを押すと閉じます。これはpopover="auto"が標準で持つライトディスミスです。

Live demo単独ページで開く ↗

最小コード

<button popovertarget="action-menu">
  操作メニューを開く
</button>

<div id="action-menu" popover>
  <button>名前を変更</button>
  <button>共有する</button>
</div>

popoverを値なしで書くとpopover="auto"と同じ動作になります。ボタンのpopovertargetは、開閉したい要素のIDを参照します。

ブラウザが担当してくれること

トップレイヤーへの表示

開いた要素は通常のz-indexの積み重なりから離れた「トップレイヤー」に置かれます。親要素のoverflow: hiddenで切れてしまう問題も避けやすくなります。

閉じる操作

autoのPopoverは、外側のクリック、Escキー、別のauto Popoverを開いたときに閉じます。常に自分でdocumentへイベントを登録する必要はありません。

CSSによる状態の装飾

開いている要素は:popover-openで選択できます。表示時のアニメーションや背景は::backdropと組み合わせられます。

[popover]:popover-open {
  opacity: 1;
  transform: translateY(0);
}

[popover]::backdrop {
  background: rgb(17 26 46 / 12%);
}

アクセシビリティの注意

  • トリガーにはbuttonを使い、操作できることを明確にします。
  • メニュー、ダイアログ、ツールチップなど、内容に合うHTML要素と役割を選びます。
  • Popoverは矢印キーによるメニュー移動までは提供しません。本格的なメニューでは別途キーボード操作を実装します。
  • 読み上げ順を自然にするため、可能ならトリガーの直後にPopover要素を置きます。

未対応ブラウザでは

"popover" in HTMLElement.prototypeで機能を検出できます。このデモでは未対応の場合にボタンを無効化し、説明を表示します。古い環境まで同じ体験が必要なら、既存のダイアログ実装やライブラリをフォールバックとして用意します。

使い分け：入力を完了するまでほかの操作を止めたい場合は<dialog>、軽い補足や操作一覧にはPopoverが向いています。
