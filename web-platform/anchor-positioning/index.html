基準要素にぴたりと付く CSS Anchor Positioning

ツールチップやメニューの座標をJavaScriptで測らず、別の要素の辺や中央をCSSの位置指定に使えます。

Baseline 2026対応状況：2026年9月1日確認

CSS Anchor Positioningは、ある要素をアンカー（基準）として名前を付け、その座標を別の要素の配置に利用する仕組みです。DOM上で親子関係にない要素も結べるため、重ねて表示するUIの設計がシンプルになります。

この記事のデモで使うanchor-name、名前付きposition-anchor、anchor()の対応範囲です。一部の新しい値や変形後の位置計算は、ブラウザごとに対応状況が異なります。

上下左右へ配置する

ボタンで吹き出しの位置を切り替えてください。吹き出しは青い基準ボタンの辺と中央を参照しています。

Live demo単独ページで開く ↗

最小コード

.target {
  anchor-name: --profile-button;
}

.tooltip {
  position: fixed;
  position-anchor: --profile-button;
  top: anchor(bottom);
  left: anchor(center);
  translate: -50% 12px;
}

anchor-nameで基準要素に名前を付け、配置する要素のposition-anchorから参照します。anchor(bottom)はアンカーの下辺、anchor(center)は中央の座標を返します。

配置の考え方

通常の位置指定と組み合わせる

anchor()はtop、right、bottom、leftなどの値として使います。そこへtranslateやcalc()を加え、吹き出しの中央揃えと余白を調整します。

/* アンカーの左側、縦中央に配置 */
.tooltip {
  right: anchor(left);
  top: anchor(center);
  translate: -12px -50%;
}

DOMの置き場所に縛られない

従来は対象要素の直後に吹き出しを置き、共通の親をposition: relativeにすることがよくありました。名前付きアンカーなら、表示要素を別の場所に置きながら位置関係を保てます。

Popoverとの相性

Popover APIが「開閉とトップレイヤー」を、Anchor Positioningが「トリガーとの位置関係」を担当します。組み合わせると、メニューライブラリが担ってきた処理の多くをブラウザ標準で表現できます。

アクセシビリティの注意

  • 視覚的な位置が変わっても、読み上げ順はDOM順のままです。意味の通る順序でHTMLを書きます。
  • 吹き出しだけに重要な情報を隠さず、キーボードやタッチでも同じ情報へ到達できるようにします。
  • ツールチップはポインターを動かすだけで閉じないよう、十分な操作領域を用意します。

未対応ブラウザでは

@supports (anchor-name: --target)で対応を判定できます。このデモでは未対応時に吹き出しをステージ内の通常配置へ戻し、位置切り替えを無効化します。

.tooltip {
  /* フォールバックの通常配置 */
  position: absolute;
  inset: auto 16px 16px;
}

@supports (anchor-name: --target) {
  .tooltip {
    position: fixed;
    position-anchor: --target;
  }
}

実務のヒント：Baseline Newly availableは「最新の主要ブラウザで利用可能」という意味です。古いOSのWebViewを対象に含める場合は、アクセス解析と実機確認も行いましょう。
