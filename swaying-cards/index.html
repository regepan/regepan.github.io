Swaying Card Animations

CSS アニメーションだけで作る「ゆれるカード」3パターン

Demo 01

🪢 Pendulum Hang — 吊り下げ振り子

transform-origin: top center を使って上端を軸に左右へ振り子のように揺れます。
各カードに異なる animation-delay を与えてランダム感を出しています。ホバーで一時停止。

🔮 Crystal Magic item
🌸 Blossom Spring vibes
🌊 Ocean Deep blue
CSS を見る 
/* 上端を軸に振り子運動 */
.hang-card {
  transform-origin: top center;
  animation: pendulum 3s ease-in-out infinite;
}
.hang-card:hover {
  animation-play-state: paused;
}

@keyframes pendulum {
  0%   { transform: rotate(-10deg); }
  50%  { transform: rotate( 10deg); }
  100% { transform: rotate(-10deg); }
}

Demo 02

🌊 Floating Drift — 浮遊ゆらぎ

translateY による上下移動と rotate を組み合わせて、水面に浮かぶような動きを再現。
4ステップの keyframes で左傾き→上昇→右傾き→上昇の繰り返しにしています。

🌿 Nature Calm & fresh
⭐ Stellar Night sky
🦋 Flutter Light as air
CSS を見る 
/* 上下移動 + 回転で浮遊感 */
.float-card {
  animation: floatDrift 4s ease-in-out infinite;
}

@keyframes floatDrift {
  0%   { transform: translateY(0px)   rotate(-3deg); }
  25%  { transform: translateY(-14px) rotate( 0deg); }
  50%  { transform: translateY(0px)   rotate( 3deg); }
  75%  { transform: translateY(-14px) rotate( 0deg); }
  100% { transform: translateY(0px)   rotate(-3deg); }
}

Demo 03

💨 Wind Sway — 3D 風なびき

perspective と rotateY で奥行きのある 3D 揺れを表現。
rotateZ と translateX を加えることで、風に押されているようなリアル感が出ます。

🔥 Ember Warm glow
🌱 Sprout New life
✨ Spark Pure energy
CSS を見る 
/* 親に perspective を設定 */
.wind-stage {
  perspective: 700px;
}

/* 3D 回転で風になびく動き */
.wind-card {
  transform-style: preserve-3d;
  animation: windSway 2.8s ease-in-out infinite;
}

@keyframes windSway {
  0%   { transform: rotateY(-18deg) rotateZ(-4deg) translateX(-4px); }
  50%  { transform: rotateY( 18deg) rotateZ( 4deg) translateX( 4px); }
  100% { transform: rotateY(-18deg) rotateZ(-4deg) translateX(-4px); }
}
